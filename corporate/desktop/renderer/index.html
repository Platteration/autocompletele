Proposals from the applications you allowed in learn mode. Accept one to save it as a shortcut; dismiss it and it is not proposed again. Highlighted parts of a template become fill-in blanks; give each a name you will recognise when filling it in.

Suggested to your organisation

Proposals you chose to share with whoever maintains your organisation's shortcuts. Exporting saves exactly the texts listed here (templates with their blanks, never the values seen in them), your team and a random desk id; nothing else.

TextYour trigger

Triggers keeps only the last 200 characters in memory to spot a trigger (and, while the organisation has keyword rules, the current field's text, up to 4,000 characters); nothing is written. Learn keeps the text you type in that application, with card numbers, passwords and tokens masked, so recurring phrases can be proposed. Off reads nothing. Credential prompts, password managers and terminals are never learned.

Keyboard

The listener turns key presses into characters with a layout table. Only English (US) is exact; the others cover the usual national keys, AltGr and dead keys (´ ` ^ ¨ ~) and are best effort. If a shortcut does not fire, type its trigger in the test box: the box shows what actle sees, and nothing typed there is kept.

Typing speed

When these words appear in what you write, a small offer or a warning appears. Rules come from the organisation policy. While there are rules, the text of the field you are typing in is held in memory (up to 4,000 characters) to check them, and dropped when you move to another field; it is never written to disk.

RuleWhenMatchDoes

Type a document shortcut in any application to list its files. Attach puts the chosen files into the message you are writing (Outlook directly, Thunderbird's compose window, otherwise pasted as files); Copy file paths and Reveal in folder are the fallbacks.

Lookups

Type a lookup trigger, a space, a key and a space (for example /cust 1001 ) to insert the matching block from your organisation's data. The data is fetched from the organisation and kept in the data folder; nothing you type is sent anywhere.
