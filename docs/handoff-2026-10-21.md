## Security review of 21 and 22 October 2026

Method: a workflow of agents over the changed files. Nine finders with
distinct lenses (filesystem and paths, parsers of outside input, the policy as
an attacker, data leakage, the Electron shell and IPC, the Sheets add-in,
typing and command injection, the engine and learning, supply chain) produced
42 raw findings, merged to 33 unique. Each unique finding was put to three
independent verifiers (reproduce it, judge scope and impact against
`SECURITY.md`, refute it); a finding stands when at least two say real and in
scope. A usage limit stopped the first run after 22 verifications; the other
11 were verified afterwards. Result: **28 confirmed (3 high, 10 medium, 15
low), 5 rejected.** Every confirmed finding is fixed on the branch, with the
residual gaps listed under **Follow-ups**. Each fix comes with a test.

### Fixed

High:

- **Decompression bomb** in a watched-folder `.docx`/`.xlsx` (dc22285):
  `core/extract.js` caps what one ZIP entry may inflate to (32 MiB).
- **Policy regular expressions could hang the desk** (ba72685): every policy
  pattern goes through `core/policy-pattern.js`, which refuses the shapes that
  backtrack exponentially (nested quantifiers, quantified alternation,
  backreferences, more than four unbounded repeats, over 256 characters) with
  a policy warning, so `actle-admin sign` refuses them; patterns see capped
  text, and on the desk run in a `vm` with a 50 ms budget
  (`desktop/pattern-runner.js`): one that runs out is turned off for the
  session and audited. The add-in gets the static check and the caps only.
- **A Sheets block of about 130,000 rows threw out of the policy parser**
  (dc22285): refused by row count; a throwing suite normaliser becomes a
  warning and an empty section.

Medium:

- "Never overwrites" was a check-then-rename (dd53204): `core/filer.js`
  `moveDocument` claims the name with `fs.linkSync` (or an exclusive copy) and
  takes the next number on `EEXIST`; the desk, undo and `admin file --apply`
  all use it.
- A symbolic link in a watched folder was read and its target copied out
  (dc22285): `lstat` everywhere, links skipped and refused.
- A filing blank named like an Object member crashed `propose` (dc22285).
- Filing values could carry a card number or secret into names, index, audit
  and notifications (dc22285): such values stay blanks; values capped.
- The filing queue recursed per file and ran without `try/catch` (dc22285).
- The filing popover took the keyboard focus when a file landed (dd53204):
  shown with `showInactive`, nothing focused, and nothing files until the
  person presses on it 700 ms after it appeared, with the focus still there.
- Forms stored typed answers and lookup rows in clear text (dd53204): a stored
  fill keeps only values that came from the policy, pruned by
  `retention.corpusDays` and deleted by "Delete learned text".
- A shared workbook's configuration silently replaced the organisation's in
  the Sheets pane (dd53204): offered with a confirmation that names what
  changes; a formula or rows block from the document's configuration is
  confirmed before it is written.
- The sender restored the clipboard on a timer that could beat the paste
  (dd53204): `desktop/adapters/sender.js` restores after the keys are sent.
- A document named `--apply` turned an `admin file` dry run into a move
  (dd53204): per-command options, `--` ends options, bare names refused with
  options, DRY RUN or APPLYING printed first.

Low (dd53204 unless noted): `admin file` resolves `~` and relative folders as
the desk does and skips directories; names are capped in code points and
bytes, folder components too, lone surrogates replaced; undo checks size and
mtime and refuses when they changed; Windows device names are checked before
the first dot (CONIN$, COM0 and superscript digits too); data files are
written 0600 and folders 0700; own-record labels no longer carry typed values;
`settings:save` keeps an allow-list, `filing:reveal` takes an index id, the
windows refuse navigation; "Never for this folder" covers a recursive parent
watch; Sheets block rows are formula-guarded; undo and trigger deletion count
code points; the send gesture (Enter, Tab, chords) ends a word and runs the
checks, and Guard offers no fix for a warning raised by it; in a password
manager, terminal or sign-in window (recognised from a list of names and
titles) the engine holds no field text and runs no check; Reply, Forms and Guard refuse while paused, and a pause closes open
popovers; Forms drops values Guard's scrubber would mask and matches more
secret field names.

### Found while fixing: Electron 44's clipboard is asynchronous (1820db8)

Electron 44.9.0, which `corporate/desktop` pins, answers
`clipboard.readText()` and `writeText()` with promises. Reply, Notes, Forms,
Guard and the documents popover were written against the synchronous API, so
on a real desk Reply and Notes would have read `[object Promise]`, Forms never
found the copied reference, and Guard and the documents popover reported text
as copied before (or without) the write. All now wait; Forms' popover asks for
the reference key through `forms:clipboardReference`, which returns only the
lookup key. `test/clipboard-async.test.js` and the fake Electron in
`test/shell-guards.test.js` answer like Electron 44.

### Rejected after verification

- Guard's clipboard fix copies the whole field, other rules' findings
  included: hygiene; a documented limit, nothing reads the copy back.
- App hooks run in the key callback without `try/catch`: not reachable without
  a modified app module on the device.
- Forms, Reply and Notes type into whichever window has the focus after the
  popover closes: robustness, not in scope; worth doing for consistency.
- `sender.press("constructor")` reaches a prototype member: unreachable, no
  impact.
- `node --test` runs `sheets-addin/test/fakes.js`: hygiene.

### Follow-ups (known gaps, not fixed)

- `desktop/adapters/input.js`: after Alt+Tab into a password manager the
  previous window's decision holds until the next 1.5 s poll; poll on
  Alt/Ctrl/Meta with Tab.
- `desktop/main.js` (pre-existing): a keyword offer raised at a space, then
  Alt+Tab and a click on Insert, pastes into the newly focused window.
- `core/store.js`: own watch folders accept a filesystem root or `~/.ssh`;
  `paletteShortcut` accepts application chords such as Ctrl+C.
- Sheets: full-width ＝＋－＠ and leading whitespace pass the formula guard;
  check in Excel and Google whether a host evaluates them. Longer term, sign
  the exported sheets section with the policy key.
- Filing: the link-then-unlink move and its exclusive-copy fallback are
  untested on Windows, FAT and SMB; reserved device names are not checked in
  folder components; undo identity is size plus mtime, not a content hash.
- Forms stores policy-derived fills even without a keychain.
- Windows: pasted text and Guard's corrected copy are not excluded from
  clipboard history or cloud sync.

### Limits of this review

No Electron, Excel or Google host was run: the shell findings and fixes rest
on reading `main.js` and the renderer code and on the fake Electron in the
tests. The second finder round (outside input variants, desk-side races,
promises versus code, availability) did not run; the clipboard bug above is
the kind it would have looked for.
